# ForteVision · Datathon 2026

Видеопроверка кассовых операций: локальная Qwen3-VL-4B-Instruct, нормативная база НБРК и веб-интерфейс с доказательными кадрами.

## Что делает сервис

- Принимает MOV до 100 МБ / 180 секунд, без обработки звука и идентификации лиц.
- Анализирует последовательность кадров в перекрывающихся временных окнах.
- Сопоставляет видимые события с семью правилами из постановления НБРК № 231 от 29.11.2019.
- Возвращает бинарный вердикт, тип, время, объяснение, 1–3 оригинальных JPEG и нормативное основание.
- Работает без внешних AI API. После загрузки весов модель использует только локальные файлы.

Это прототип для поддержки проверки специалистом. Отсутствие найденного события не доказывает соблюдение всех процедур. Неполные фрагменты, действия вне кадра, мелкие предметы и новый ракурс могут снижать качество. Шкала confidence не является калиброванной вероятностью.

## Архитектура

`MOV → PyAV / кадры с PTS → Qwen3-VL → события / локальные правила → объединение событий → оригинальные кадры → FastAPI / UI`

`forte/rules.json` содержит краткие формулировки, ссылки, условия и исключения. Применение нормы выбирается из фиксированного набора: модель не генерирует номера законов. Веса не используются как хранилище нормативных текстов. Например, отсутствие физического удостоверения не доказывает отсутствие цифровой идентификации, а один сотрудник в клиентской операции не считается нарушением пункта 42.

## Запуск на GPU

Проверенное окружение: NVIDIA L4, PyTorch 2.8.0 + CUDA 12.8, Python 3.12, Transformers 4.57.1. Около 9 ГБ весов, от 12 ГБ VRAM и 16 ГБ RAM. Для конкретной нагрузки проверяйте запас памяти.

```bash
export FORTE_HOME=/home/ubuntu/forte-datathon
mkdir -p "$FORTE_HOME"
git clone https://github.com/song-ev/Datathon-2026.git "$FORTE_HOME/src"
python3.12 -m venv "$FORTE_HOME/.venv"
"$FORTE_HOME/.venv/bin/pip" install torch==2.8.0 torchvision==0.23.0 --index-url https://download.pytorch.org/whl/cu128
"$FORTE_HOME/.venv/bin/pip" install -r "$FORTE_HOME/src/requirements.txt"
"$FORTE_HOME/.venv/bin/python" "$FORTE_HOME/src/scripts/download_model.py"
bash "$FORTE_HOME/src/scripts/run.sh"
```

Для воспроизводимого скачивания задайте `MODEL_REVISION` сохранённым SHA из `model-manifest.json`. Во время обработки установлены `HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`, отключена телеметрия Hugging Face. У процесса нет клиентов внешних модельных API.

Первый запуск создаёт случайный API-ключ в `$FORTE_HOME/private/api-key.txt` с правами `0600`. Ключ передаётся жюри отдельно от Git. В интерфейсе кнопка «API-ключ» сохраняет его в sessionStorage текущей вкладки.

Сервис слушает порт 8000. Публикуйте его через HTTPS reverse proxy; доступ к API защищён ключом. Если Brev требует NVIDIA login, автоматическая проверка жюри не сможет пройти: для **этого порта приложения** нужен публичный HTTPS-адрес. Не публикуйте Jupyter или SSH без отдельной защиты.

Dockerfile предоставлен для переноса (сборку контейнера следует отдельно проверить):

```bash
docker build -t fortevision .
docker run --gpus all --rm -p 8000:8000 -v /path/to/forte-data:/data fortevision
```

Каталог `/data` должен быть доступен UID 1000 для записи, а веса — находиться в `/data/models/Qwen3-VL-4B-Instruct`.

## API жюри

```bash
curl -X POST https://YOUR_HOST/api/v1/analyze \
  -H "X-API-Key: YOUR_KEY" -F "file=@example.mov"
# {"job_id":"..."}
curl https://YOUR_HOST/api/v1/jobs/JOB_ID -H "X-API-Key: YOUR_KEY"
```

Ответ POST: 202. Статусы задания: `processing`, `done`, `failed`. Готовый ответ содержит `verdict: violation | no_violation`, `violations`, поля `type`, `timecode_sec`, `description`, `evidence_frames[].timestamp_sec`, `evidence_frames[].image_base64`. Дополнительно: `normative_reference`, `confidence`, `analysis`.

Ошибки: 401 — ключ, 415 — расширение, 422 — некорректное видео, 413 — размер, 429 — GPU занят (повторить через Retry-After), 503 — модель ещё загружается. Один GPU обрабатывает одно задание; очередь не растёт скрыто. Worker принудительно перезапускается при превышении 280 секунд. Незавершённые задания после перезапуска получают `failed`.

`GET /api/v1/health` — готовность без секретов. `GET /api/v1/rules` — база норм, требует ключ. Документация схемы: `/docs`.

Видео и JSON заданий удаляются после 24 часов хранения, проверка очистки каждые 5 минут. Датасет разработки в `data/` этим правилом не затрагивается.

## Оценка качества

Исходный набор: 42 файла, 40 уникальных SHA-256, 21 уникальный положительный / 19 отрицательных. Два дубликата группируются. Для одного положительного дубликата размечены разные времена — сохраняются обе отметки.

Разделение детерминированное и стратифицированное по SHA: 24 development / 16 holdout (8+8). Сценарные дубликаты, не совпадающие побайтно, не размечены, поэтому это ограничение оценки. Разметка содержит только бинарный класс и время: точность классификации типов по ней измерить нельзя.

```bash
export PYTHONPATH="$FORTE_HOME/src"
"$FORTE_HOME/.venv/bin/python" "$FORTE_HOME/src/scripts/evaluate.py" --split dev
# Выбор EVENT_THRESHOLD только на development, затем один зафиксированный запуск:
EVENT_THRESHOLD=0.65 "$FORTE_HOME/.venv/bin/python" "$FORTE_HOME/src/scripts/evaluate.py" --split holdout
"$FORTE_HOME/.venv/bin/python" -m unittest discover -s "$FORTE_HOME/src/tests" -v
"$FORTE_HOME/.venv/bin/python" "$FORTE_HOME/src/scripts/api_smoke.py"
```

Полные предсказания и описания остаются в `private/`. В терминал выводятся только агрегаты. Тесты жюри не используются для обучения или подбора порогов. Итоговые измерения публикуются отдельно после завершения оценки; синтетический smoke-тест не является оценкой качества на реальных видео.

## Бюджет и эксплуатация

Один L4 в Brev: плановый тариф $0.88/час, бюджет проекта $50. 12 часов ≈ $10.56, 48 часов ≈ $42.24. Это расчёт, не установленный лимит провайдера. Остановите инстанс через Brev после проверки жюри; хранение диска может продолжать тарифицироваться. Остановка Python-процесса не останавливает оплату VM.

Датасет, модель, журналы с содержимым видео и ключи исключены из Git. Модель Qwen3-VL-4B-Instruct опубликована под Apache-2.0; её лицензия сохраняется вместе с загруженными весами.
